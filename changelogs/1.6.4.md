# Smithing fix, F1, optional level cap

- Smithing: shift-click crafting now pays XP and rolls returns (was 0 XP); shift-click on furnace output now rolls bonus ingots; bonus ingots roll on the count actually taken (GitHub #9)
- Skills screen: smelting listed as a bonus-ingot source, not an XP source (it never gave XP)
- F1 hides the skill XP bar on every version (GitHub #8)
- Inventory "Skills" tab re-positions every frame — no longer left behind when the recipe book opens (GitHub #5)
- New optional `extendedLevels` (default OFF) + `extendedMaxLevel` (default 999, 101–999): skills level past 100, bonuses keep their formula (level 200 = double level 100). Only values that would break the game are capped (chances at 100%, recovery time floor, sneak visibility floor, Lure V). Turning it off never deletes XP (GitHub #6)
- Level cap is the server's setting, synced to clients
