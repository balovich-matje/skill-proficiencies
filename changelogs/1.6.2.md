# Config rename + HUD compat options

- Config file is now `config/skill-proficiencies.json`. An existing `config/specialities.json` is renamed on first load — settings carry over untouched, nothing to do by hand
- New `hudShiftAmount` (default 7): how far the vanilla XP bar, hearts, food and armor are raised. Set it to `0` to leave the vanilla HUD exactly where it was — for Raised, Nostalgic Tweaks, Melancholic Hunger and anything else that moves those rows
- New `hudBarYOffset` (default 0): moves the skill XP bar itself up or down, for when another mod has already shifted the hotbar out from under it
- Both are client-local, never synced, same footing as `showXpHudBar`. 26.2/26.1: Mod Menu config screen, Interface category. Older versions: edit the json
- Skills screen is titled "Skill Proficiencies"; the inventory tab keeps its short label
- Mod id, namespace and saved skill data stay `specialities` — no world data is touched
