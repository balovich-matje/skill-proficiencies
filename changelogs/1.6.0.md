# HUD bar toggle

- New config `showXpHudBar`: hide the skill XP bar; the vanilla XP bar, hearts, food and armor drop back to their standard position. Default on
- Client-side setting, never synced — a server cannot hide your bar, and yours hides nobody else's
- 26.2/26.1: toggle it in the Mod Menu config screen, new Interface category. Older versions: edit `showXpHudBar` in config/specialities.json
- Level-up toasts, the skills screen and the stealth vignette are unaffected
