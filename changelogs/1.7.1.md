# Vanilla-style skill bar

- Skill XP bar now looks like the vanilla XP bar (notches, shading), in each skill's colour
- New subtle bar animations: a glint on XP gain, a tick when a segment fills, one gentle pulse per XP gain near a level-up, and a colour fade when switching skills
- Removed the flying tool icons
- Defence tooltip shows max health in points, like vanilla tooltips
